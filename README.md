# ProjectsDashboard

Um painel que mostra informações de um checklist.

## O que foi utilizado?

- HTML
- CSS
- JavaScript
- Tailwind CSS

## Objetivo

Facilitar a visualização de quais construções dos vídeos eu já havia construido. Sendo assim, o painel fornece:

- Quantas construções já foram realizadas.
- Quantas construções faltam.
- A porcentagem de conclusão.
- A playlist dos vídeos.
- A quantidade total de itens.

## O que foi treinado?

- Construção um código em inglês.
- Uso do LocalStorage.
- Uso do Framework Tailwind CSS.
- Lógica de programação.
- Uso de JSON.

## Como você pode utilizar?

Basta alterar dentro do Javascript a lista para a lista que queira. Atente-se ao formato da lista.

## Como usar o projeto?

1. Clone o projeto.
2. Altere o Javascript para a lista que queira.
3. Abra no navegador e veja as métricas.
4. Baixe e carregue em JSON para testar.
